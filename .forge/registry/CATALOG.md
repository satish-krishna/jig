### `api.infrastructure-module` — InfrastructureModule (csharp)
- **Intent:** One call wires the database and repositories, so the host does not know EF Core details.
- **Reuse:** Call services.AddInfrastructure(connectionString) from the API composition root, then InitializeDatabaseAsync on startup.
- **Where:** `services/api/src/Jig.Infrastructure/InfrastructureModule.cs`
